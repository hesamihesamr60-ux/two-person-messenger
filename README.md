# پیام‌رسان دو نفره

نیازمندی: Node.js

اجرا:
1. `npm install`
2. `npm start`
3. مرورگر: `http://localhost:3000`

برای تست دو نفر، آدرس را در دو پنجره باز کنید و دو نام متفاوت وارد کنید.
برای استفاده از دو دستگاه روی اینترنت، پروژه را روی یک سرور عمومی Deploy کنید و هر دو دستگاه را به همان آدرس وصل کنید.
